# 开放平台 API 手册

## 一、接入与鉴权

所有接口使用 HTTPS，基础地址为 https://api.example.com/v1。鉴权方式为 Bearer Token：在请求头中携带 `Authorization: Bearer <access_token>`。

Access Token 有效期 2 小时，过期后使用 Refresh Token 换取新令牌。Refresh Token 有效期 30 天，只能使用一次，刷新后旧令牌立即失效。

## 二、限流规则

默认限流为 100 QPS（每秒请求数），按应用维度统计。超出阈值返回 HTTP 429，响应头中包含 `X-RateLimit-Remaining` 与 `Retry-After`。

建议实现指数退避重试：首次间隔 1 秒，之后每次翻倍，最多重试 5 次。持续超限可提交工单申请提额，需说明业务场景与预估峰值。

## 三、错误码

| 错误码 | 含义 | 处理建议 |
| --- | --- | --- |
| 400 | 参数错误 | 检查请求体字段类型与必填项 |
| 401 | 令牌无效或过期 | 重新获取 Access Token |
| 403 | 无权限访问该资源 | 检查应用权限范围 |
| 404 | 资源不存在 | 确认 ID 是否正确 |
| 429 | 触发限流 | 退避重试或申请提额 |
| 500 | 服务端异常 | 携带 request_id 联系技术支持 |

## 四、Webhook 回调

事件推送采用 POST JSON 格式，需在 5 秒内返回 2xx，否则视为失败。失败会重试 3 次，间隔分别为 5 秒、30 秒、300 秒。全部失败后标记为投递失败并发送告警邮件。

回调需校验签名：使用应用密钥对 `timestamp + body` 做 HMAC-SHA256，与请求头 `X-Signature` 比对。时间戳偏差超过 5 分钟应拒绝。

## 五、批量接口

批量查询单次最多 100 条，批量写入单次最多 500 条。单条记录大小不超过 256 KB，超过请拆分。

## 六、SDK 与示例

提供 Node.js、Python、Java、Go 四种语言的 SDK。SDK 内置重试与限流保护，推荐优先使用。示例代码见开放平台文档中心。
