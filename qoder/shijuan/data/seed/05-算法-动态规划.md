# 动态规划

## 两个前提

一个问题能用动态规划求解，需要同时满足两点。第一是最优子结构：问题的最优解由子问题的最优解组合而成，这意味着可以写出递归式。第二是重叠子问题：递归过程中同一个子问题会被反复求解，因此把结果缓存下来才有意义。

如果子问题互不重叠，递归式退化为分治，缓存没有收益；如果无法写出由子问题最优解组合出的递归式（例如子问题之间互相制约），则要考虑区间 DP 或状态压缩，甚至问题本身不可解。

## 状态定义的方法

动态规划的难点几乎全在状态定义。一个好的状态应该满足三点：能唯一确定一个子问题的答案；状态之间能通过一步决策转移；状态数乘以转移代价在可接受范围内。

常用的切入方式是「以某个位置结尾」。最长上升子序列定义 dp[i] 为以第 i 个元素结尾的最长上升子序列长度，转移时枚举前一个元素 j，若 a[j] < a[i] 则 dp[i] = max(dp[i], dp[j] + 1)。这个定义的妙处在于把「选哪些元素」的自由度收敛成「上一个选的是谁」。

## 0-1 背包

给定 n 件物品，每件有重量 w 和价值 v，背包容量 C，每件最多选一次，求最大价值。定义 dp[i][j] 为前 i 件物品、容量为 j 时的最大价值，转移分不选与选两种情况：

dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])

一维优化时容量必须逆序枚举。原因是 dp[j-w] 需要的是上一轮的值，正序枚举会让同一件物品被重复使用，那就变成完全背包了。

## 完全背包与多重背包

完全背包每件物品可选无限次，一维写法把容量改为正序枚举即可。多重背包每件物品有数量上限，朴素做法是拆成 k 个 0-1 物品，复杂度 O(n C k)；二进制拆分把 k 拆成 1、2、4、…、剩余，物品数降到 O(log k)，再用 0-1 背包求解。

## 最长公共子序列

设 A 长度 m、B 长度 n，dp[i][j] 表示 A 前 i 个字符与 B 前 j 个字符的最长公共子序列长度。若 A[i] == B[j]，dp[i][j] = dp[i-1][j-1] + 1；否则 dp[i][j] = max(dp[i-1][j], dp[i][j-1])。

这个转移体现了动态规划处理「不匹配时舍弃哪一边」的思路，和编辑距离的转移几乎同构，只是编辑距离在不匹配时取三种操作的最小值。

## 空间优化与恢复方案

如果只需要最终答案，二维表可以压成一维，用滚动数组；注意一维化后遍历方向要保证依赖的是上一轮的值。如果需要输出具体方案，则必须保留完整表用于回溯，或者额外记录每一步的决策来源。

时间复杂度的估算方式是状态数乘转移代价。0-1 背包是 O(nC)，LCS 是 O(mn)，区间 DP 通常是 O(n^3)。当状态数过大时，可以考虑状态压缩、单调队列优化或决策单调性优化。
