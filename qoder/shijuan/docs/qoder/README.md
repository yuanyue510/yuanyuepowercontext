## 每张图怎么拍

一个阶段三张，缺一不可：

1. **Qoder 对话框**：你的提问 + 它给的方案/代码（滚动到能看见关键那段）。
2. **它改动的文件**：编辑器里的 diff 或文件树，能看出是新建还是修改。
3. **终端输出**：该阶段对应的命令跑通的结果（例如 `npm run seed` 的导入报告、`npm run verify` 的 27 项）。

## 三个注意

- 截图里若有 IP、手机号、邮箱、token，先遮挡再存。
- 对话时间要和 commit 时间对得上，别把十步挤在五分钟里。
- 某步 Qoder 写错了、你手动改了，把「它写成 X、我改成 Y、原因是 Z」也截进去——比一路顺利更可信。
