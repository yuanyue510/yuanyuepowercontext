## 三、技术结合（seekdb 实际作用）

| 用途 | 实现 | 可核对的地方 |
|---|---|---|
| 数据存储 | 每个资料集一张表：`VECTOR(512)` + ngram2 全文 + JSON metadata | `npm run verify` 打印物理表列类型与 `FULLTEXT + VECTOR` 索引 |
| 检索 | `hybridSearch()` → `DBMS_HYBRID_SEARCH`，RRF(k=60) **在库内融合** | `evidence/verify.json` 记录三种模式 top1 与耗时；`VERIFICATION.md` §3 |
| 记忆 | `sj_learners` / `sj_questions` / `sj_weakpoints` / `sj_reviews` 四表，按「学习者+资料集+概念」唯一 | `VERIFICATION.md` §2：写入 → 新会话读回 → `mastered`；`evidence/verify-log.txt` 有直接查库的行 |

一句话分工：**文档走 seekdb 的向量+全文混合检索，学习记忆走 seekdb 的 SQL 表**，同一个实例、同一个库 `shijuan`。
