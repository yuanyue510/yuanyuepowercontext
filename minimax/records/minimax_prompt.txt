# 开发任务
为订单查询增加状态过滤与最低金额过滤，并修复金额汇总的浮点误差

# 必须遵守的规格（来自 seekdb，含来源行号）

## [ORDER-REQ-005] 按最低金额过滤
来源: specs/order-query.md:49

`list_orders(min_amount=...)` 必须筛出金额 **大于等于** `min_amount` 的订单（闭区间下界）。
比较必须使用 `Decimal`，不得先转成 `float` 再比较。
`min_amount=None` 表示不限制金额；与 `customer_id`、`status` 同时出现时取交集。

## [ORDER-REQ-007] 金额汇总精度
来源: specs/money.md:3

`total_cents(order_ids)` 汇总给定订单金额并返回**整数分**。

1. 累加过程必须使用 `Decimal`，禁止用 `float` 累加后再乘 100 取整；
2. 结果必须是精确到分的整数，例如 19.99 + 0.01 必须得到 2000 分，而不是 1999 分；
3. 空列表返回 0；
4. 该函数只做汇总，不修改任何订单状态。

## [ORDER-REQ-008] 已取消订单不计入合计
来源: specs/money.md:16

`total_cents` 必须跳过状态为 `cancelled` 的订单。
该规则对退款后的订单同样生效：订单退款后再次汇总时不得计入其金额。

## [ORDER-REQ-004] 订单状态过滤
来源: specs/order-query.md:34

`list_orders(status=...)` 必须按订单状态筛选：

1. `status` 支持单值，如 `status="paid"`；
2. `status` 支持逗号分隔的多值，如 `status="created,cancelled"`，多值之间取并集；
3. 多值两侧的空白需要忽略，如 `status="paid, shipped"`；
4. 出现任何不在 `created` / `paid` / `shipped` / `cancelled` 中的取值时，必须抛出
   `ValueError`，不得静默忽略；
5. `status=None` 表示不按状态限制。

## [ORDER-REQ-003] 单条查询与退款
来源: specs/order-query.md:24

`get_order(order_id)` 返回对应订单，订单不存在时抛 `KeyError`。
`refund(order_id)` 仅允许 `paid` / `shipped` 状态整单退款，退款后状态置为 `cancelled`；
对 `created`（未支付）或 `cancelled`（已退款）状态调用必须抛 `ValueError`。

## 文件 ordersvc/repository.py 符号 OrderRepository (第 23-57 行)
```python
class OrderRepository:
    """内存实现，接口形状与生产环境的 DB 仓储保持一致。"""

    def __init__(self) -> None:
        self._orders: Dict[str, Order] = {}
        self.reset()

    def reset(self) -> None:
        self._orders = {
            oid: Order(
                order_id=oid,
                customer_id=cid,
                status=status,
                amount=Decimal(amount),
                created_at=created_at,
            )
            for oid, cid, status, amount, created_at in _SEED
        }

    def all(self) -> List[Order]:
        # 保持插入顺序，列表接口的行为依赖这一点
        return list(self._orders.values())

    def get(self, order_id: str) -> Order:
        try:
            return self._orders[order_id]
        except KeyError as exc:
            raise KeyError(f"order not found: {order_id}") from exc

    def save(self, order: Order) -> None:
        self._orders[order.order_id] = order

    def extend(self, orders: Iterable[Order]) -> None:
        for order in orders:
            self.save(order)
```
